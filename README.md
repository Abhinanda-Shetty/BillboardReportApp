# FOLLOW THESE STEPS:

- Create a fresh Folder in your laptop
- Open the folder in VScode
- Open the terminal (better if it is gitbash )


- Clone your repo <br>
<code>git clone PasteTheUrlUnderCodeOPtion </code>

- Go into the project folder <br>
<code> cd projectname/frontend </code>

- Install frontend dependencies <br>
  <code> npm install</code> 

- New terminal <br>
  <code> cd projectname/backend </code>

- Install backend dependencies <br>
  <code> npm install </code>

 #                 ||                                         SETUP DONE CONGRATULATIONS 👏👏👏👏                               ||
 
 
 
 
 
 
 ## Once you open Folder every time: 
 - Each time you open : <code> git pull origin main </code>

 - Stage changes
<code> git add .</code>

- Commit changes
<code> git commit -m "Update style or...." </code>

- Or Add and commit changes in onestep :
  <code> git commit -am "Updated ..... " </code>
  
- Push to main branch
<code> git push  </code> Now code is saved in Github...

## To run only frontend <br>
- <code> cd frontend </code>  <br>
<code> npm start </code>

## To run only backend : <br>
- <code> cd backend </code> <br>
<code> node index.js </code>

## To run both frontend and backend : <br>
<code> npm run start:all </code>
